Experiemnt 3

For experiment 3, I selected the physics engine option, for which I selected the plugin matter.js
I wanted to create a radial 'planet' gravity experiment and this required adding the matter attactors plugin for matter.js.
I used a P5 example of this plugin being used as my code base. I made the matter attactor centred and unable to be moved by the mouse
while making the attracted bodies movable by mouse.
For the first variant, I introduced some inital perpendicular inertia to some of the bodies to cause them to orbit the planet.
For the second variant, I added a sound effect for the physics collisions.
