Experiment 2

Experiment 2 is an audio visualiser which plays back audio when clicked by the user and desplays it's waveform in a circle
It also displays information about the volume percentage
The code base for it was a P5 experiment found online, which I have included linked in the comments at the bottom of each experiment.
The audio can be swapped out for any MP3 file.
The variants of this experiment include swapping out the mp3 file for microphone input and changing some of the visuals.
